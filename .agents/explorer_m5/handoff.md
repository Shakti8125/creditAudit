## 2. Logic Chain
1. *RS256 JWT mismatch*: RS256 is an asymmetric cryptographic signature scheme. Passing a symmetric key string causes python-jose / PyJWT to raise runtime format errors.
2. *Alembic target_metadata omission*: Alembic determines database schema by inspecting 	arget_metadata = Base.metadata. Because env.py only imports user.py and pp/models/__init__.py is empty, Base.metadata never registers documents and document_chunks. Autogenerated migrations will fail or emit DROP TABLE statements.
3. *Multi-tenancy indexing*: In a multi-tenant SaaS architecture, all queries scope by 	enant_id. Without B-tree indexes on 	enant_id, PostgreSQL executes sequential table scans, degrading performance and increasing lock contention.
4. *Pydantic v2 Schema validation*: DocumentMetadata has chunk_count: int with rom_attributes=True. When validating from ORM Document instances, missing attribute raises Pydantic ValidationError.
5. *SSE Streaming buffering*: Reverse proxies like Nginx and AWS ALB buffer HTTP responses unless X-Accel-Buffering: no and Cache-Control: no-cache headers are explicitly sent.
