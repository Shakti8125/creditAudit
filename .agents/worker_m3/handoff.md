# Milestone 3: Document Extraction & Chunking — Handoff Report

## 1. Observation
- **DOC-01 (`backend/app/services/chunker.py:40-55`)**: `current_part` was unconditionally reset to `""` on every loop iteration, emitting single snippets rather than accumulating text up to `self.chunk_size`.
- **DOC-02 (`backend/app/services/chunker.py:94, 110-111`)**: Markdown tables generated by Docling (`| ... |`) had row words evaluated individually. Rows with fewer than 8 words were dropped by `if len(rc_clean.split()) >= 8:`, deleting metric tables and financial ratios.
- **DOC-03 (`backend/app/services/chunker.py:12-14, 58-115`)**: `self.overlap` was initialized in `__init__` but never used in `_split_text` or `chunk()`, producing chunks with 0 overlap.
- **DOC-04 (`backend/app/services/chunker.py:36, 43, 88`)**: Splitting on `". "` and `" "` stripped sentence-ending punctuation and whitespace during reassembly.
- **DOC-05 (`backend/app/services/chunker.py:82, 88, 110`)**: Empty lines were stripped via `if line.strip():`, removing double newlines (`\n\n`) required for paragraph-level semantic splitting.
- **DOC-06 (`backend/app/services/document_extractor.py:40-47`)**: Raw exceptions during `self.converter.convert()` bubbled up unhandled as 500 server crashes.
- **DOC-07 (`backend/app/services/document_extractor.py:23-29`)**: `format_options` in `DocumentConverter` only configured `InputFormat.PDF`, omitting `InputFormat.DOCX: WordFormatOption()`.
- **Service Exports (`backend/app/services/__init__.py`)**: File was empty, lacking re-exports of `MarkdownChunker` and `DocumentExtractor`.

## 2. Logic Chain
1. **Accumulation & Overlap Logic (DOC-01, DOC-03)**:
   - Designed and implemented `_accumulate_with_overlap(self, units: List[str], separator: str) -> List[str]`.
   - Iterates through atomic text units, accumulating them into `current_units` until adding the next unit exceeds `self.chunk_size`.
   - Upon reaching `self.chunk_size`, emits the accumulated chunk and computes trailing overlap units whose total character length is $\le \text{self.overlap}$.
   - Seeds the subsequent chunk with these trailing units, ensuring context continuity across chunk boundaries without splitting tokens or words mid-way.
2. **Table Preservation & Exemption (DOC-02)**:
   - Added `_is_table_line(self, line: str) -> bool` to detect Markdown table lines (`| ... |`).
   - Grouped section lines into contiguous `"text"` and `"table"` blocks.
   - Handled table blocks as atomic chunks prefixed with `header_context`, explicitly exempting them from the 8-word row filter.
3. **Punctuation & Semantic Paragraph Preservation (DOC-04, DOC-05)**:
   - Preserved empty lines in `current_section_lines` so paragraph boundaries (`\n\n`) are retained.
   - For sentence splitting (delimiter `". "`), used regex lookbehind `re.split(r"(?<=[.!?])\s+", clean_text)` so periods, exclamation marks, and question marks remain attached to their respective sentences.
   - Preserved financial numbers with commas (e.g., `1,250,000`) and bracketed privacy tokens (e.g., `[BANK_1]`).
4. **Structured Error Handling & DOCX Support (DOC-06, DOC-07)**:
   - Defined `DocumentExtractionError(Exception)` and wrapped `self.converter.convert()` in `_convert()` with `try...except Exception as exc: raise DocumentExtractionError(...) from exc`.
   - Added `InputFormat.DOCX: WordFormatOption()` to `format_options` in `DocumentExtractor.__init__`.
5. **Re-Exports**:
   - Re-exported `MarkdownChunker`, `DocumentExtractor`, and `DocumentExtractionError` in `backend/app/services/__init__.py`.

## 3. Caveats
- `DocumentConverter` from `docling` downloads layout and table recognition models on first runtime invocation in cold environments; in airgapped or test environments, ensure network access or pre-cached Hugging Face / EasyOCR weights.
- When an individual table is larger than `self.chunk_size`, it is preserved as an atomic unit to maintain markdown table syntax integrity.

## 4. Conclusion
All 7 assigned issues (DOC-01 through DOC-07) and package re-exports have been fully implemented and verified. The document extraction and chunking pipeline maintains complete fidelity for financial numbers, privacy tokens, markdown tables, sentence punctuation, and hierarchical header contexts.
