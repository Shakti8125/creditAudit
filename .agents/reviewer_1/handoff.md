## 2. Milestone-by-Milestone Verification Matrix

### Milestone 1: Foundation, Dependencies & Database Models
- **DEP-01, DEP-02**: Migrated from unmaintained `python-jose` and `passlib` to modern `PyJWT[crypto]>=2.8.0` and direct `bcrypt` (`hashpw`/`checkpw`) in `app/utils/security.py`. Ephemeral 2048-bit RSA PEM fallback keys generated for development.
- **DEP-03, DEP-04**: Added Docling runtime C-libraries (`libgl1`, `libglib2.0-0`, `libgomp1`) and pre-downloaded wheel for `spacy` in `Dockerfile`.
- **DEP-05..08**: Upgraded to `pinecone>=5.0.0`, removed redundant `langchain-*` and unused packages (`tiktoken`, `presidio-anonymizer`), updated `pydantic-settings>=2.4.0`.
- **CFG-01, CFG-04**: Separate RSA public/private PEM keys in `config.py` / `security.py`; deprecated `datetime.utcnow()` replaced with `datetime.now(timezone.utc)`.
- **MOD-01**: `alembic/env.py` explicitly imports `Tenant`, `User`, `Document`, `DocumentChunk` ensuring complete autogenerated migrations.
- **MOD-02**: `User.tenant_id`, `Document.tenant_id`, `Document.user_id`, and `DocumentChunk.document_id` foreign keys indexed with `index=True`.
- **MOD-03, MOD-04, MOD-05**: `DeclarativeBase` subclassed in `db/database.py`; `pool_pre_ping=True` enabled; all ORM models re-exported in `models/__init__.py`.
- **SCH-01, SCH-02, SCH-03**: `Document.chunk_count` property added to ORM model; `model_config = ConfigDict(from_attributes=True)` added across all schemas in `app/schemas/`; public re-exports in `schemas/__init__.py`.

### Milestone 2: Privacy Pipeline
- **PRV-01**: `MaskingPipeline.mask_document()` implements reverse start-character offset slicing (`masked_text[:span["start"]] + token + masked_text[span["end"]:]`), eliminating index drift and text corruption.
- **PRV-02, PRV-03, PRV-04**: `EgressValidator` verifies original registered entities via `registry.get_mapping().keys()`, filters valid bracket masking tokens via `VALID_TOKEN_PATTERN` to eliminate false positives, and supports singleton dependency injection.
- **PRV-05, PRV-06, PRV-07**: `BankNameMatcher` uses half-open interval `end_index = end_char_index + 1`, lowercase Aho-Corasick automaton, and `isalnum()` word boundary checks. Typo `"Barclids"` fixed to `"Barclays"`.
- **PRV-08, PRV-09, PRV-10**: Removed runtime `spacy.cli.download` (raises clean `RuntimeError`); expanded `FINANCIAL_PATTERNS` to cover GCC currencies (`AED`, `SAR`, `QAR`, `KWD`, `BHD`, `OMR`), comma numbers (`1,250,000`), dates, and fiscal quarters; Presidio shares spaCy engine instance.
- **PRV-11, PRV-12**: `EntityRegistry.unmask_text()` performs atomic single-pass regex replacement with length-descending token sorting; `mask()` strips whitespace.

### Milestone 3: Document Extraction & Chunking
- **DOC-01, DOC-03**: `MarkdownChunker` accumulates atomic units up to `self.chunk_size` and implements sliding window overlap via `_accumulate_with_overlap`.
- **DOC-02**: Markdown tables (`| ... |`) detected via `_is_table_line` and treated as atomic chunks exempt from the 8-word filter.
- **DOC-04, DOC-05**: Delimiter splitting uses regex lookbehind `re.split(r"(?<=[.!?])\s+", clean_text)` to preserve sentence punctuation, spacing, and paragraph breaks.
- **DOC-06, DOC-07**: `DocumentExtractor` wraps Docling conversions in `try...except` raising `DocumentExtractionError`; `WordFormatOption` added for `InputFormat.DOCX`.

### Milestone 4: LLM Routing & Resilience
- **LLM-01, LLM-02**: `LLMRouter.generate_stream()` implemented directly as an async generator yielding tokens, with automatic fallback from NVIDIA to Gemini on startup error.
- **LLM-03, LLM-04**: `CircuitBreaker` provides dedicated `call_stream()` async generator method and uses `asyncio.Lock` to guard state transitions.
- **LLM-05, LLM-06**: `NvidiaProvider` uses relative URL `"ranking"` with structured payload `{"query": {"text": ...}, "passages": [{"text": ...}]}`; `aclose()` coroutines added for client cleanup.
- **LLM-07**: Default parameter values (`temperature=0.7`, `max_tokens=1024`) added to abstract `BaseLLMProvider` signatures and concrete implementations.

### Milestone 5: NeMo Guardrails Integration
- **GRD-01, GRD-02**: `GuardrailsService` safely extracts content from dict responses (`response.get("content", "")`) and passes `context` and `retrieved_contexts` into `self.rails.generate_async()`.
- **GRD-03, GRD-04**: `rails.co` defines `flow bot refuse to respond`; `config.yml` pins `colang_version: "2.x"` and defines single main engine.
- **GRD-05, GRD-06**: `actions.py` validates placeholder integrity against `ALLOWED_PLACEHOLDER_PATTERN`; hallucination detection filters English stop words and preserves comma numbers.

### Milestone 6: Hybrid RAG Retrieval Pipeline
- **RET-01, RET-02, RET-03**: `PineconeStore` has default parameters from `settings.pinecone`, implements `upsert_chunks()`, and safely guards empty index stats (`getattr(stats, "namespaces", None) or {}`).
- **RET-04, RET-05**: Logging added to Pinecone error handlers; synchronous calls offloaded with `asyncio.to_thread`.
- **RET-06, RET-07**: `_fetch_chunks_for_document` strictly joins `Document` and filters by `Document.tenant_id == tenant_id`; `CBUAE_REGULATORY_CORPUS` indexed for BM25 when `document_id is None`.
- **RET-08, RET-09, RET-10**: `BM25Okapi.fit()` resets state; regex tokenization preserves comma numbers; `avgdl == 0` guarded against `ZeroDivisionError`.
- **RET-11, RET-12, RET-13, RET-14**: `DenseRetriever` queries namespaces in parallel via `asyncio.gather`; `Reranker` clones candidate objects with `model_copy(update=...)` and falls back to top-N candidates on API error; `rrf_fuse` normalizes scores to $[0, 1]$.

### Milestone 7: Model Validation Analytics
- **ANA-01, ANA-02, ANA-03, ANA-04**: `ModelMetricsExtractor` preserves comma numbers (Rule 10), fixes unit regex `(?P<unit>%|percent|bps|bp)?`, handles Markdown tables, and normalizes basis points (`bps / 100`).
- **ANA-05, ANA-06, ANA-07**: `PolicyChecker` normalizes unflagged percentages, aligns AUC thresholds to CBUAE standards (`< 0.70` BREACH, `0.70-0.75` WARNING, `>= 0.75` PASS), and validates calibration metrics (Hosmer-Lemeshow, Brier score, PD accuracy ratio).
- **ANA-08, ANA-09**: `EarlyWarningDetector` normalizes observed vs. predicted ratios and adds `MEDIUM` severity warning for moderate PSI drift ($0.10 \le \text{PSI} \le 0.25$).

### Milestone 8: API Endpoints, Middleware & Dependencies
- **API-01, MID-01**: Pydantic `TokenPayload` attribute access (`current_user.tenant_id`) used across `query.py`, `compare.py`, `gap_analysis.py`, `regulatory.py`, `documents.py`, and `rate_limiter.py`.

## 3. 5-Component Handoff Section

### 1. Observation
- Static inspection of ~50 source files confirmed all 120 remediation patterns from `backend_code_audit_report.md` are present, correctly typed, and syntactically sound.
- Direct execution of `test_llm_router.py` verified:
  - Primary provider routing to `nvidia`.
  - Automatic failover to `gemini` on NVIDIA API failure.
  - Circuit breaker transition to `OPEN` state after 5 consecutive failures.
- Direct execution of `test_privacy.py` verified that missing `en_core_web_lg` spaCy model raises an informative `RuntimeError` rather than blocking the event loop or attempting unsafe runtime downloads.

### 2. Logic Chain
1. *Observation*: Reverse character offset slicing (`masked_text[:span["start"]] + token + masked_text[span["end"]:]`) replaces entities strictly from back to front.
   *Inference*: Character offsets for preceding spans remain valid throughout replacement, completely eliminating index drift and substring corruption.
2. *Observation*: `_fetch_chunks_for_document` in `hybrid_retriever.py` and API endpoints join `Document` and filter `Document.tenant_id == tenant_id`.
   *Inference*: Multi-tenant query isolation is enforced at the database level, preventing any cross-tenant data leaks.
3. *Observation*: `TokenPayload` attribute access (`current_user.tenant_id`) replaces `current_user.get('tenant_id')` across all handlers and middleware.
   *Inference*: Eliminates all 5 reported `AttributeError` crashes and ensures rate limiter and multi-tenancy filters function properly.

### 3. Caveats
- **SQLite Engine Pool Arguments**: In `app/db/database.py`, `pool_size=5` and `max_overflow=10` are configured on `create_async_engine`. While standard for PostgreSQL (`postgresql+asyncpg://`), running tests with SQLite (`sqlite+aiosqlite:///:memory:`) requires omitting these pool kwargs or running against a PostgreSQL test database.
- **Gemini Health Check Method**: In `gemini_provider.py` line 158, `self.client.aio.models.get_model` should be `self.client.aio.models.get`. In the `google-genai` SDK, `health_check()` catches this and reports `status="DOWN"`. Generation, streaming, and embeddings are unaffected because they call `generate_content` and `embed_content`.
